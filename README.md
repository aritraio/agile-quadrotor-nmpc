## Project Overview
An autonomous aerial robotics stack consisting of a 6-DoF trajectory optimization system using **Non-Linear Model Predictive Control (NMPC)** coupled with a **15-State Error-State Extended Kalman Filter (ES-EKF)** for IMU/Vision fusion. The controller solves a non-linear constrained optimization problem online at 50–100 Hz, accounting for rotor dynamics, motor limits, aerodynamic drag, and dynamic obstacles.

## Mathematical Foundations & Control Formulation

### 1. Non-linear Quadrotor Dynamics on $SO(3)$
The continuous state vector is $\mathbf{x} = [\mathbf{p}^\top, \mathbf{v}^\top, \mathbf{q}^\top, \boldsymbol{\omega}^\top]^\top \in \mathbb{R}^{13}$ and control input $\mathbf{u} = [f_T, \boldsymbol{\tau}^\top]^\top \in \mathbb{R}^4$:

* **Position & Velocity Kinematics:**
  $$\dot{\mathbf{p}} = \mathbf{v}$$
  $$m\dot{\mathbf{v}} = m\mathbf{g} + \mathbf{R}(\mathbf{q})\mathbf{f}_T - \mathbf{D}\mathbf{v}$$
  where $\mathbf{R}(\mathbf{q}) \in SO(3)$ is the rotation matrix derived from unit quaternion $\mathbf{q}$, and $\mathbf{D} = \text{diag}(d_x, d_y, d_z)$ is the translational rotor drag coefficient matrix.

* **Attitude Kinematics & Angular Momentum:**
  $$\dot{\mathbf{q}} = \frac{1}{2}\mathbf{q} \otimes \begin{bmatrix} 0 \\ \boldsymbol{\omega} \end{bmatrix}$$
  $$\mathbf{J}\dot{\boldsymbol{\omega}} = \boldsymbol{\tau} - \boldsymbol{\omega} \times (\mathbf{J}\boldsymbol{\omega})$$
  where $\mathbf{J}$ is the quadrotor inertia tensor and $\boldsymbol{\tau}$ is the body torque vector generated by differential rotor thrusts.

### 2. Optimal Control Problem (OCP)
Formulate the tracking problem over a receding horizon $T$ discretized into $N$ intervals with step size $\Delta t$:

$$\min_{\mathbf{x}_{0:N}, \mathbf{u}_{0:N-1}} \sum_{k=0}^{N-1} \left( \|\mathbf{x}_k - \mathbf{x}_{k,\text{ref}}\|_{\mathbf{Q}}^2 + \|\mathbf{u}_k - \mathbf{u}_{k,\text{ref}}\|_{\mathbf{R}}^2 \right) + \|\mathbf{x}_N - \mathbf{x}_{N,\text{ref}}\|_{\mathbf{P}}^2$$

**Subject to:**
* **Discretized Dynamics:** $\mathbf{x}_{k+1} = \mathbf{f}_{\text{RK4}}(\mathbf{x}_k, \mathbf{u}_k)$ (explicit 4th-order Runge-Kutta discretization)
* **Actuator Saturation:** $0 \le u_{i,\min} \le u_{i,k} \le u_{i,\max} \quad (i = 1, \dots, 4)$
* **Tilt Angle Constraints:** $\|\mathbf{q}_{\text{xy}}\|^2 \le \sin^2(\theta_{\max}/2)$
* **Ellipsoidal Obstacle Avoidance:**
  $$(\mathbf{p}_k - \mathbf{p}_{\text{obs}})^\top \mathbf{A}_{\text{obs}} (\mathbf{p}_k - \mathbf{p}_{\text{obs}}) \ge 1$$

### 3. Error-State Extended Kalman Filter (ES-EKF)
* **Error State Representation:** True state is modeled as $\mathbf{x}_{\text{true}} = \mathbf{x}_{\text{nominal}} \oplus \delta\mathbf{x}$.
* **Error State Vector:** $\delta\mathbf{x} = [\delta\mathbf{p}^\top, \delta\mathbf{v}^\top, \delta\boldsymbol{\theta}^\top, \delta\mathbf{b}_a^\top, \delta\mathbf{b}_g^\top]^\top \in \mathbb{R}^{15}$.
* **IMU Propagation (500 Hz):** High-frequency open-loop integration of accelerometer and gyroscope signals.
* **Measurement Updates (30–60 Hz):** Fused visual odometry / motion-capture poses to estimate and inject error state, followed by error reset $\delta\mathbf{x} \leftarrow \mathbf{0}$.

### Technical Stack
* **Language:** Modern C++ (C++20, standard concepts, constexpr configuration).
* **Solvers:** CasADi (symbolic auto-differentiation & C-code generation) or `acados` (Real-Time Iteration SQP solver with `qpOASES` / `HPIPM` backend).
* **Linear Algebra:** Eigen 3 with SIMD vectorization enabled (`-O3 -march=native -mavx2`).
* **Simulation:** MuJoCo C API or Isaac Sim / ROS 2 Humble.
* **Memory Management:** Zero heap allocations during steady-state control cycles; static pre-allocated workspace buffers.

## Implementation Roadmap

### Phase 1: Dynamics & Numerical Integration
* Implement the $SO(3)$ quaternion math and continuous 6-DoF quadrotor dynamic model.
* Build explicit 4th-order Runge-Kutta integrator (`RK4Integrator`).
* Write unit tests validating energy conservation in unforced motion and quaternion normalization.

### Phase 2: 15-State ES-EKF Fusion
* Implement IMU nominal state propagation with discrete transition matrix $F_k$ and noise covariance $Q_k$.
* Implement measurement update step with visual odometry pose inputs.
* Simulate IMU sensor noise (bias drift, random walk) and verify covariance consistency.

### Phase 3: NMPC Solver Integration
* Define the Optimal Control Problem in CasADi/acados.
* Auto-generate C source files for the SQP real-time iteration.
* Benchmark loop solve times on target CPU (must stay strictly under $10\,\text{ms}$ for 100 Hz operation).

### Phase 4: Full Simulation & Aggressive Trajectories
* Bridge solver with MuJoCo quadrotor model.
* Execute high-speed figure-8 trajectories, aggressive flips, and dynamic obstacle avoidance.
* Measure tracking RMSE and control latency under artificial wind gusts.
